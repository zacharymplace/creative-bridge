# Collaborator Profile Packet

Version: 0.4.0

The Collaborator Profile Packet helps artists, editors, producers, musicians, designers, developers, and other creative contributors describe what kinds of projects they are open to considering.

This is not a profile system, marketplace, account, hiring board, messaging layer, or certification process.

It is a preparation standard.

## What the packet should clarify

A prepared collaborator profile should explain:

- role lanes
- mediums and formats of interest
- collaboration types open for consideration
- AI-adjacent comfort levels
- credit expectations
- compensation and scope boundaries
- contact boundaries
- public attribution boundaries
- dream-team / opt-in discovery preferences
- what should never be implied without consent

## Required packet parts

1. Collaborator profile
2. Role interest statement
3. Collaboration boundaries
4. Readiness checklist pass

## Non-goals

The packet does not create:

- public profiles
- accounts
- messaging
- marketplace behavior
- hiring workflows
- public collaborator tagging
- implied project attachment
- certification
- endorsement
- verification

## Suggested order

1. Fill the collaborator profile template.
2. Fill the role interest template.
3. Fill the collaboration boundaries template.
4. Review the collaborator readiness checklist.
5. Revise anything unclear before expressing interest or accepting outreach.
