# Project Profile Checklist

A lightweight self-assessment for Creative Bridge project profiles.

This is not certification, verification, or endorsement. It is a readiness pass to help creators describe AI-assisted projects clearly, respectfully, and collaboration-first.

## Transparency

- [ ] The project states its current tier.
- [ ] The project states its intended next tier.
- [ ] The project explains how AI was used.
- [ ] The project avoids presenting AI-assisted work as fully human-made.

## Human Authorship

- [ ] The human creator's role is clear.
- [ ] The project identifies what humans decided, wrote, edited, directed, revised, or finished.
- [ ] AI is framed as assistive scaffolding, not the author.

## AI-Use Disclosure

- [ ] The disclosure is specific enough to understand the workflow.
- [ ] The disclosure does not hide material AI involvement.
- [ ] The project avoids copying or invoking a living artist's identity.

## Role Clarity

- [ ] Roles already involved are listed.
- [ ] Roles needed are listed.
- [ ] Each needed role has a clear collaboration type.
- [ ] No role implies someone is attached before they agree.

## Compensation and Scope Clarity

- [ ] Paid roles are marked as paid.
- [ ] Speculative roles are clearly marked as speculative.
- [ ] Advisory/community roles are clearly distinguished.
- [ ] Scope, deliverables, timeline, or next milestone are stated.

## Dream-Team Boundaries

- [ ] Dream-team language is framed as private or opt-in aspiration.
- [ ] No public pressure, mass tagging, or implied attachment is used.
- [ ] Outreach expectations are respectful and limited.

## Human-Finished Pathway

- [ ] The project explains how it could move toward human craft.
- [ ] The profile identifies what would need to be redrawn, revised, edited, produced, or finished by humans.
- [ ] The pathway does not treat human craft as cosmetic cleanup.

## Next Milestone

- [ ] The next concrete milestone is stated.
- [ ] The milestone fits the current stage.
- [ ] The milestone does not imply marketplace behavior.

## Non-Marketplace Behavior

- [ ] No forms.
- [ ] No messaging.
- [ ] No accounts.
- [ ] No public collaborator tagging.
- [ ] No claims of certification.
- [ ] No claims that collaborators are attached unless they are explicitly involved.
