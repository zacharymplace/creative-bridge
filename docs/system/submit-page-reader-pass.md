# Submit Page Reader Pass

Version: 3.36.0

The Submit page should explain what can be submitted without implying open acceptance, endorsement, or approval.

## Decision

Refine `/submit` into a practical submission-boundaries guide.

## Reader order

- What submission is for
- Submission types
- What not to submit
- How submissions are handled
- Escalation paths

## Principle

Submission should create reviewable material, not implied approval or automatic participation.
