# System Map Reader Pass

Version: 3.39.0

The System Map page should help readers understand how the public system fits together without treating every route as equally important.

## Decision

Refine `/system-map` into a practical route-and-relationship guide.

## Reader order

- What the system map is for
- Primary reader paths
- System lanes
- Gated and archive areas
- Escalation paths

## Principle

A system map should clarify relationships and routing, not overwhelm readers with every artifact at once.
