# Projects Page Reader Pass

Version: 3.42.0

The Projects page should explain listed projects without implying endorsement, certification, approval, ranking, or marketplace status.

## Decision

Refine `/projects` into a practical project-context guide.

## Reader order

- What projects are for
- What listing does not mean
- Project context fields
- Review posture
- Escalation paths

## Principle

A project listing should provide context for review, not public status.
