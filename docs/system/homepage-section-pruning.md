# Homepage Section Pruning

Version: 3.13.0

The homepage should now act as an entry system, not a full archive.

The narrative hierarchy section carries the orientation load. Redundant sections should be removed or demoted so the page reads faster and with more discipline.

## Decision

Keep the homepage focused on:

- Hero
- Narrative hierarchy
- Position
- Problem
- Standard
- Manifesto
- Footer

## Pruned from homepage

- How it works
- Project tiers
- For creators
- For collaborators
- Transparency

These concepts remain available through deeper routes and documentation.

## Principle

A public homepage should create direction.

It should not attempt to prove the entire system.
