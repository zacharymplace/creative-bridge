# Review Intake Reader Pass

Version: 3.30.0

The Review Intake page should make external critique easy to submit without turning review into praise.

## Decision

Refine `/review-intake` into a practical critique-submission guide.

## Reader order

- What review intake is for
- What useful critique includes
- What not to submit
- How critique is handled
- Escalation paths

## Principle

Review intake should collect pressure, not approval.
