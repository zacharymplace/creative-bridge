# Outreach Kit Reader Pass

Version: 3.33.0

The Outreach Kit page should help people share The Creative Bridge without overstating what it is.

## Decision

Refine `/outreach-kit` into a practical sharing guide with safe copy boundaries.

## Reader order

- What the outreach kit is for
- Safe ways to describe the project
- Unsafe claims to avoid
- Suggested outreach uses
- Escalation paths

## Principle

Outreach should invite critique and understanding, not approval theater or false authority.
