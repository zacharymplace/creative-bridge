# Launch Copy Reader Pass

Version: 3.37.0

The Launch Copy page should provide public language that invites review without implying approval, endorsement, certification, or launch hype.

## Decision

Refine `/launch-copy` into a practical safe-launch-language guide.

## Reader order

- What launch copy is for
- Safe launch language
- Unsafe launch language
- Suggested uses
- Escalation paths

## Principle

Launch copy should invite scrutiny and comprehension, not authority claims or approval theater.
