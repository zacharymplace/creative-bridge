# Homepage Hero Simplification

Version: 3.15.0

The homepage hero should not compete with the narrative hierarchy section.

## Decision

Simplify the hero into a restrained entry statement with three actions:

- Start here
- Review
- Standard

## Removed from hero emphasis

- Duplicate explanation already handled by narrative hierarchy
- Competing button language
- Overextended thesis copy

## Principle

The hero should create immediate orientation, then hand off to the guided hierarchy.
