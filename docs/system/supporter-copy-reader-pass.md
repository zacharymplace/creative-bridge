# Supporter Copy Reader Pass

Version: 3.50.0

The Supporter Copy page should define safe supporter language without implying endorsement, approval, influence, trust status, or governance power.

## Decision

Refine `/supporter-copy` into a practical supporter-language and recognition-boundary guide.

## Reader order

- What supporter copy is for
- What supporter copy must avoid
- Safe language patterns
- Unsafe language patterns

## Principle
