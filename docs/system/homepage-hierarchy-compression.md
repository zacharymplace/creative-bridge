# Homepage Hierarchy Compression

Version: 3.16.0

The homepage should move quickly from orientation to action.

The narrative hierarchy section should support the hero, not become a second homepage inside the homepage.

## Decision

Compress the homepage hierarchy section into:

- one boundary statement
- three primary paths
- four system lanes

## Changed

- Removed dense side-by-side “what this is / what this is not” cards from the homepage.
- Preserved the same logic inside narrative hierarchy documentation.
- Kept the homepage focused on scan speed.

## Principle

A homepage should create confidence and direction before asking for deep reading.
