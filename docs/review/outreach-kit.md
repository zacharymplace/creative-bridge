# Outreach Kit

Version: 1.8.0

The Outreach Kit provides copyable, role-specific reviewer messages.

Outreach should be specific, low-pressure, and review-oriented.

The ask is not praise, promotion, participation, or endorsement.

The ask is targeted criticism.

## General public post

I built The Creative Bridge as a public standard for AI-assisted creative work that should move toward human collaboration, not artist replacement. I’m looking for focused criticism, not praise or feature requests. If you’re willing to pressure test the standard, start here: https://creative-bridge-wheat.vercel.app/review

## Artists

Subject: Quick critique request on an AI/collaboration standard

Message:

I built a public standard called The Creative Bridge. It argues that AI-assisted creative work should move people toward human collaboration, not replace artists. I’m looking for criticism from an artist’s perspective: where does this still leave room for artist replacement, vague credit, style laundering, or AI-assisted work being passed off as human-made?

Review entry: https://creative-bridge-wheat.vercel.app/review
