# Whyfiles

Version: 2.1.0

Whyfiles are public rationale records.

They explain why major Creative Bridge rules, rejections, guardrails, and design choices exist.

Whyfiles are not release notes. They are reasoning records for the standard.


## Categories

Whyfiles are grouped into:

- Disclosure
- Consent
- Credit
- Governance
- Review
- Platform

These categories make the rationale layer easier to inspect as a system.
