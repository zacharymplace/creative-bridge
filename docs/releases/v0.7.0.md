# The Creative Bridge v0.7.0

## Release focus

v0.7.0 adds the Rejected Patterns Registry.

This release makes the project’s boundaries more explicit by documenting behaviors the standard will not support.

## Added

- `/rejected-patterns`
- Rejected Patterns Registry content module
- Rejected Patterns Markdown doc
- v0.7.0 release note
- Static export QA coverage for rejected-pattern artifacts

## Explicitly rejected

- style impersonation
- hidden AI use
- public collaborator tagging
- implied attachment
- fake certification
- collaborator-as-legitimacy-prop behavior
- marketplace drift without governance review
- pressure-based recruitment
- vague credit
- AI asset dumping

## Principle reinforced

The standard should be clearest where it says no.
