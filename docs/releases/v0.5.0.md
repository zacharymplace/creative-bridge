# The Creative Bridge v0.5.0

## Release focus

v0.5.0 adds the Public Trust Layer.

This release creates a single readable reference for the project’s anti-replacement stance, disclosure model, consent boundaries, credit boundaries, accessibility framing, and non-platform discipline.

## Added

- `/trust`
- Public Trust Layer content module
- Trust Layer Markdown doc
- v0.5.0 release note
- Static export QA coverage for trust artifacts

## Still not included

- accounts
- public profiles
- messaging
- marketplace behavior
- payments
- certification
- verification
- endorsement
- AI asset hosting

## Principle reinforced

The project should become easier to criticize and govern before it becomes more capable.
