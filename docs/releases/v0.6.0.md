# The Creative Bridge v0.6.0

## Release focus

v0.6.0 adds the Governance Layer.

This release defines how the standard changes over time and which future product capabilities require explicit review before implementation.

## Added

- `/governance`
- Governance Layer content module
- Governance Layer Markdown doc
- v0.6.0 release note
- Static export QA coverage for governance artifacts

## Requires explicit review before implementation

- accounts
- submissions
- public profiles
- messaging
- payments
- marketplace behavior
- public collaborator discovery
- public collaborator tagging
- scoring algorithms
- certification
- verification
- endorsement
- AI asset hosting

## Principle reinforced

The project should create governance pressure before gaining platform power.
