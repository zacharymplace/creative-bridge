# The Creative Bridge v0.8.0

## Release focus

v0.8.0 adds the Review Rubric Layer.

This release creates a public rubric for evaluating project profiles without turning the process into certification, endorsement, verification, or ranking.

## Added

- `/review-rubric`
- Review Rubric Layer content module
- Review Rubric Markdown doc
- v0.8.0 release note
- Static export QA coverage for rubric artifacts

## Rubric categories

- transparency
- consent boundaries
- role clarity
- credit specificity
- AI-use disclosure
- human-finished pathway
- rejected-pattern risk

## Explicit non-goals

- certification
- endorsement
- verification
- ranking systems
- algorithmic authority
- marketplace scoring
- hidden moderation

## Principle reinforced

Projects should become easier to evaluate without creating artificial authority.
