# The Creative Bridge v0.4.0

## Release focus

v0.4.0 adds the collaborator-side packet.

This release balances the creator submission packet by giving artists, editors, producers, musicians, designers, developers, and other contributors a static preparation standard for role lanes, AI-adjacent comfort, credit expectations, contact boundaries, and opt-in discovery preferences.

## Added

- `/collaborate`
- Collaborator Profile Packet
- Collaborator Readiness Checklist
- Collaborator profile template
- Role interest template
- Collaboration boundaries template
- Static export QA coverage for collaborator artifacts

## Still not included

- accounts
- public profiles
- messaging
- marketplace behavior
- hiring workflows
- public collaborator tagging
- implied project attachment
- certification
- verification
- endorsement

## Principle reinforced

Collaborators should not be treated as interchangeable labor or publicly attached to a project without explicit consent.
