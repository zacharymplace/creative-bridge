# Review Rubric Layer

Version: 0.8.0

The Review Rubric Layer defines how Creative Bridge project profiles can be evaluated without turning the process into certification, endorsement, or verification.

## Position

The rubric exists to improve clarity and accountability.

It is not:

- certification
- endorsement
- verification
- a ranking system
- algorithmic authority
- marketplace scoring
- hidden moderation

## Review categories

### Transparency

Does the project clearly describe:

- current tier
- intended next tier
- AI-use disclosure
- production state

### Consent boundaries

Does the project avoid:

- public collaborator tagging
- implied attachment
- pressure-based recruitment
- unclear outreach behavior

### Role clarity

Are collaborator roles, collaboration types, scope, and expectations understandable?

### Credit specificity

Does the project distinguish human contributions from AI-assisted scaffolding?

### AI-use disclosure

Is AI involvement visible enough to understand how the project was developed?

### Human-finished pathway

Does the project explain how it could move toward stronger human craft involvement over time?

### Rejected-pattern risk

Does the project avoid behaviors listed in the Rejected Patterns Registry?

## Rubric scale

### strong

The project demonstrates clear alignment with the Bridge standard.

### acceptable

The project is generally aligned but could improve clarity or boundaries.

### needs work

The project lacks clarity, disclosure, consent boundaries, or role definition in important areas.

## Principle reinforced

The rubric should improve accountability without becoming approval theater.
